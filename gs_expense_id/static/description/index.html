Expense IDs

Give every expense a permanent ID, such as EXP-00001, with a prefix you choose.

Automatic

Every new expense gets the next ID when it is created, including split expenses. Existing expenses get IDs when you install the app.

Permanent

IDs never change when an expense is edited, and every ID is unique.

Your format

Change the prefix (for example EXP- to CLAIM-) and the next number in Settings. Existing IDs keep their old prefix.

Expense IDs in the list

Every expense gets an Expense ID column you can sort and search.

On the expense form

The ID shows above the expense description, so it is easy to quote in emails and approvals.

Choose your prefix

Go to Expenses > Configuration > Settings > Expense IDs to set the prefix and the next number.

Good to know

  • Works with Odoo Community and Enterprise, in the Expenses app.
  • No configuration is needed to start. IDs have five digits by default.
  • Free and open source under the LGPL-3 licence.
