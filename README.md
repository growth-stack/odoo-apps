# Growth Stack Odoo apps

Free apps published on the Odoo Apps Store. Each Odoo version has its own branch (`20.0`, ...).

| App | Technical name | Needs |
| --- | --- | --- |
| Customer and Vendor IDs | `gs_customer_vendor_id` | Invoicing |
| Employee IDs | `gs_employee_id` | Employees |
| Expense IDs | `gs_expense_id` | Expenses |
| Product IDs | `gs_product_id` | Products (any app) |

All apps are LGPL-3.
